Tiny Chess v7 — 4 KB Python chess engine. Alpha-beta search with quiescence, null-move pruning, LMR, aspiration windows, futility pruning, transposition table, killer + history move ordering. Evaluation: material + piece-square centrality + king tropism + pawn structure + king safety, all integer math. Deterministic: a fixed node budget per move (45,000 nodes), never a clock. Python 3.13 standard library only.

## Run it

```sh
python3 main.py
```
